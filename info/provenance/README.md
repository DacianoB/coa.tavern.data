# Provenance and publication scope

Source: `DacianoB/coatavern`, commit
`4a34030e2523fbc36cde440025ac89ed55f92c7c`. The tracked source working tree was
clean when inspected and remains unchanged. Database collection/export is read
only. This is a separate archive; no original Git history or deployment
configuration is published.

[source-files.json](source-files.json) identifies the copied extraction/import
logic and reference files. [The raw manifest](../../raw/manifest.json) identifies
every original raw file, relative path, size and SHA-256, plus archive hashes.
The DB manifest records the export time, original types, keys and exact counts.

## Original files versus generated exports

Raw ZIP members preserve their original bytes and repository-relative paths.
The original broken-save `.luax` is included and explicitly marked; it was not
repaired. Different extraction folders remain separate so alternate copies of
client Lua are not silently merged. Raw file presence does not prove every record
was imported; raw captures can contain fields absent from the database.

The original database uses PostgreSQL. `game.db` and `community-game.db` are new
portable SQLite exports of the available stored data. Original IDs/table/column
names are preserved. Source import dates and row provenance may be incomplete.

The parsed scaling JSON is copied from the original project and was independently
regenerated byte for byte from its raw inputs during verification.

## Included

- Raw item captures, dense/sparse scaling dumps, extracted DBC and client Lua,
  extracted icons, and AtlasLoot source/game-data cache, as raw release archives.
- All rows/columns of explicitly selected game and derived helper tables,
  including empty tables and placeholder records.
- Original scraping addons, extraction/import scripts, relevant query/SQL logic,
  historical notes and newly organized Markdown findings/schema documentation.

`reference/tavern` contains original source for reading the reconstruction logic;
it is not a runnable application. Historical Markdown has a context banner and
personal local paths generalized. The optional base importer has one protective
adaptation: its original table-clearing operation is replaced by an empty-target
check. The byte-preserved original is also included at
`reference/original-scripts/import-ascension-client-data.ts` to document precisely
what the historical importer did. Original comments and third-party notices are retained.

## Excluded

Credentials, environment files, mixed private backups, app/community accounts,
profiles, favorites, builds, comments, sessions, combat logs, website administration
and unrelated personal addon settings. Full installed MPQ archives outside the
source repository were not copied.

Import logs and builder import envelopes can contain local paths or unrelated
metadata and are omitted. Numeric `source_import_id` values remain on applicable
game rows, but those private import envelopes are not in the snapshot. The
original external builder JSON and CoaExporter addon source were not present in
the inspected repository; available imported rows are retained.
