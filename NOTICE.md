# Attribution and scope

The MIT license covers the original extraction scripts, addons, export tools,
and documentation contributed by this project. It does not relicense game
content, extracted records, client assets, or third-party code/data.

The game records and terminology originate from World of Warcraft and Project
Ascension / CoA. This is an independent community research archive, not an
official server database or an endorsement by either project.

The legacy table naming and schema originate from
[AzerothCore AoWoW](https://github.com/azerothcore/aowow). Consult its upstream
license when using its schema or code. The schema bootstrap downloads upstream
SQL; that material retains its own licensing.

AtlasLoot-derived records retain their source module, relative Lua path, and
line number in the exported tables. The local addon version/commit was not
recorded; the snapshot does not claim a more precise upstream origin.
The raw archives include the available AtlasLoot source, extracted DBC/Lua files and icons, with original attribution retained. Full installed MPQ archives are not bundled.

Original Tavern source provenance and adaptations are recorded in
[info/provenance](info/provenance/README.md). A public download is not a claim
that third-party game content is MIT licensed.
